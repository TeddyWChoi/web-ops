회의 개요
항목
내용
일시

안건
SF2 한국 런칭(12/8) + 글로벌 시즌2 팀별 진행 현황 점검
참석
사업, 웹기획·디자인, IT DEV(웹 개발), 인프라(SRE), 플랫폼
요약
심사용 홈페이지(11/13)는 구조·구성 확인 수준으로 제작 중이며, IT DEV는 일정상 문제없다고 보고했습니다.
19세 미만 접근 제한은 로그인 시 API 토큰 발행 방식이 Papaya 플랫폼 구조상 SF2 전용 변경이 불가해, 웹·런처·클라이언트 인증 구조 전체를 공통 플랫폼 기준으로 재검토합니다.
한국 라이브 서버 IDC 업그레이드를 오늘 진행하고, 심의용 QA 서버(메모리 8GB→16GB)를 QA 서버로 쓸 수 있는지 확인합니다.
한국 전용 CDN이 필요하며, QA용은 테스트 서버에 임시로 띄운 웹·도메인을 사용합니다.
등급분류는 늦어도 10월 말(일정표상 10/28) 접수합니다.
카드사 심사는 통상 2주, 최대 3주로 확인됐으며 현재 일정상 12/8 런칭에 맞출 수 있다고 판단했습니다.
시즌2 빌드는 약 80% 준비됐고, 11월 추가 패치에서 상품·이벤트를 점검한 뒤 최종 확정합니다.
스팀 접속은 글로벌로만 분류하고, 한국 이용자는 국내 포털로 가입·접속합니다.
팀별 논의 내용
웹기획·디자인 (테디 팀장)
기반 웹페이지 디자인과 사전예약 페이지 제작을 마치고 QA 검수 단계입니다.
사전예약 페이지는 기획·디자인이 대부분 끝나 개발 중입니다.
개인정보 관리책임자는 현재 이진우 실장님 책임으로 기재돼 있으며, 회사 정책 확인 후 최종 확정합니다.
미성년자 문구는 우선 '19세 이상' 확인 체크를 넣었고, 법무 검토 결과에 따라 유지·수정·삭제합니다.
IT DEV · 웹 개발 (김영환 팀장)
11/13까지 PG사·연령제한 심사용 테스트 페이지를 먼저 제작합니다. 기본 구조와 구성을 확인할 수 있는 수준이면 충분합니다.
11/13 이후 실서비스용 추가 기능 구현과 QA를 진행해 12/10까지 맞추는 것을 목표로 합니다. 일정상 문제는 없을 것으로 예상합니다.
19세 미만 접근 제한: 이용자 로그인 시 API 토큰을 발행하는 방식을 계획했으나, 기반 Papaya 플랫폼 구조를 SF2만을 위해 추가 개발·변경할 수 없어 작업 방식 재검토가 필요합니다.
결제 화면: 1차 오픈은 기존 레이아웃에서 SF2만 선택하는 형태로 구성합니다. 신규 게임이 추가되면 글로벌처럼 포털에서 게임을 고르는 통합 결제 구조로 전환을 검토하며, EOS·대항해시대는 현행 독립 구조를 유지합니다.
분석·어드민: 공통 서비스에 게임을 추가하면 데이터 수집과 어드민 연동이 자동 적용됩니다. 별도 선행 개발 없이 적용 여부 확인 일정만 유지합니다.
게임 클라이언트·플랫폼
시즌2 빌드는 약 80% 준비됐습니다. 11월 추가 패치에서 상품·이벤트를 점검한 뒤 최종 빌드를 확정합니다.
웹에서 확인한 미성년자 정보를 연계해 인게임에서 미성년자 접속을 차단하는 방향으로 개발 중입니다.
스팀 접속은 글로벌 서비스로만 분류하고, 한국 이용자는 국내 포털로 가입·접속합니다.
인증 구조: 기존안은 웹의 게임 시작 버튼으로 런처를 실행하고 인증·미성년자 차단은 클라이언트에서 처리하는 방식이었습니다. 공통 플랫폼 구조, 보안, 유지보수, 국가별 인증 정책상 예외 구조가 될 수 있다는 우려가 나와, 게임을 공통 플랫폼 인증 체계에 맞추는 방향을 포함해 재검토합니다.
인프라 (SRE)
오늘 한국 라이브 서버 IDC(블레이드) 업그레이드를 진행합니다(회의 시점 약 10분 후). 다음 주부터 서버 세팅을 시작해 빠르면 10월 내 전달할 예정입니다.
라이브 서버 스펙은 기존 서버 1대 기준으로 선정해 여유가 빠듯하며, 유럽 기준처럼 QA 서버를 여러 대 두기는 어렵습니다.
심의(인증 기관)용으로 만든 QA 서버는 메모리 8GB→16GB로 업그레이드됩니다. 이 서버를 QA 서버로 쓸 수 있는지 확인을 요청했습니다. 우선 한국 심의 서버를 올려보고 추가가 필요하면 요청합니다.
저장소 관련 내용은 이메일과 Jira 티켓으로 공유했습니다.
한국은 별도 CDN이 필요합니다. QA용 CDN은 테스트용 개발 서버에 임시로 띄운 웹과 도메인을 사용합니다.
사업
늦어도 10월 말까지 등급분류 심사를 접수해야 하며, 관련 작업을 진행 중입니다.
안티치트 연동이 불안정해 추가 테스트가 필요하며, 개발팀에서 확인 중입니다.
라이브 서버 세팅 후 구성과 일정을 점검하고 계속 업데이트해 공유합니다.
다음 회의부터 회의록은 민재 님이 정리해 전달합니다.
카드사 심사는 통상 2주, 최대 3주 소요됩니다. 11/13까지 접근 가능한 심사용 임시 페이지만 있으면 신청할 수 있고, 심사 후 약 1주의 테스트 기간을 확보할 수 있습니다.
PG사 2차 미팅은 10/23(금) 전후로 진행해 협의를 마무리합니다.
