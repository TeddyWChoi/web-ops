회의 밖 결정 · 논의

  • 10/9 사전예약은 휴대폰 번호 수집 방식으로 결정
  • 10/12 사전예약 문자 인증 확정. SMS 발송은 2회 방향, 통신사 회신 후 안 되면 제외
  • 10/12 성인 인증: 15세 등급을 받더라도 19세 이용 불가로 서비스. 웹 가입 시 나이 확인 후 DB에 19세 인증 여부 저장, 게임 로그인 시 클라이언트에서 확인해 차단. 클라이언트 쪽은 추가 개발 필요. 웹은 게임 시작·설치 시 19세 안내 팝업만 표시
  • 10/12 결제: 빌링사 페이레터에서 게임별 결제 비율을 따로 설정할 수 있어 스포2는 별도 비율로 정리. 별도 환전 구조 불필요
  • 10/12 카드사 심사: 대부분 2주, 최대 3주. 통과하지 못한 카드사는 빼고 런칭. 홈페이지는 11/16까지 확인 가능하게 (김영환 팀장 합의)
  • 10/12 등급 신청, PG 내용 정리 완료. 확률 고지 등은 법적 강제가 아닌 권고 사항이나 런칭 전 반영
  • 10/13 웹 관련 소통 창구는 고민제 PM으로 (10/12 결정 변경). 요청, 회의 소집, 검수 의견 취합, 일정 관리를 고민제 PM이 맡고, 김충곤 팀장은 한동안 회의에 함께 참석해 확인. 고민제 PM을 통해 해결되지 않는 건은 김충곤 팀장에게
  • 10/13 일정 관리: 고민제 PM이 WBS·일정표를 관리하고 주간 보고. 이 페이지 양식을 참고해 표준 양식을 정하고, 각 팀 팀장이 진행 상황을 공유하고 크로스 체크
  • 10/13 이번 프로젝트의 절차는 런칭 후 컨플루언스에 정리해 다음 프로젝트에 활용
  • 10/13 11/16 카드사 심사용 홈페이지 범위: 홈 화면, 결제(충전) 페이지, 로그인·마이페이지(파파야플레이 공통 페이지 연결). 나머지 메뉴는 "준비중"으로 막아둠
  • 10/12 소통 창구: 디자인·웹 문의와 검수 의견은 김충곤 팀장 한 사람으로. 웹 작업·수정 요청도 김충곤 팀장이 전달 (10/13 고민제 PM으로 변경). 지승철은 사전예약 마무리 후 빠지고, 사이트 QA 단계에 다시 참여
10/2 (금)킥오프 · 한국 런칭 서버 인프라 구성과 일정

원래 글로벌 서버에서 한국 리전으로 연결할 계획이었으나, 법무 검토 후 대표님 판단으로 한국 단독 런칭으로 바뀌었습니다. 전체 일정은 기존 공유안을 유지합니다.

결정

  • 게임 서버 오픈 시 2대. 예상 동접 800명이지만 방 단위 자원 할당으로 서버당 약 90개 방만 생성 가능해 2대가 필요. 오픈 2~3개월 후 동접 1,000명 아래면 1대 감축 검토
  • DB 서버 글로벌과 같이 3대 (게임, 로그, 통합). 통합은 운영 안정 후 검토. 인프라 측은 한번 분리하면 나중에 합치기 더 어렵다는 의견
  • 기타 서버 매니지먼트, 메신저, 인포메이션 서버는 글로벌과 같은 세트, 스펙은 낮춤
  • 게임 시작 버튼 런처 미설치 시 다운로드, 설치 시 런처 실행. 해외와 동일
  • 웹 19세 체크 게임 시작 시 무조건 구현. API에 클라이언트용 연령 플래그도 함께 준비 (10/12 변경: 차단은 클라이언트, 웹은 안내 팝업)
  • 사전예약 도메인 별도 사이트 없이 sf2.papayaplay.co.kr/register 하위 경로
  • 로고 SKILL 부제 유지
  • 정기 회의 매주 금요일 9:30, 30분. 10/16부터 시작

주요 논의

  • 성인 인증 파파야플레이는 통합회원이라 가입 단계에서 미성년자를 거를 수 없음. 웹과 클라이언트에서 로그인이 따로 이뤄지고 계정이 연동되지 않아, 웹에서만 막으면 우회 가능. 웹 로그인 단일화는 원빌드 구조상 글로벌까지 영향 (10/12 결정: 인증은 한 번만, 게임 클라이언트 로그인 시 웹 DB의 19세 인증 여부를 확인해 차단)
  • 사전예약 휴대폰 수집 시 SMS 비용, 개인정보·마케팅·위탁 동의 약관 필요. 본인인증으로 CI를 받으면 번호를 바꿔도 중복을 걸러낼 수 있음. 비용 문제로 반대 시 파파야 회원가입 후 버튼 방식으로 축약
  • 재화 파파야 코인은 현금 1:1이라 글로벌처럼 환율로 가격을 맞출 수 없음. 가격을 다르게 하면 아이템 테이블이 분리되어 원빌드 불가 (10/12 변경: 빌링사 페이레터에서 게임별 결제 비율을 설정할 수 있어 스포2는 별도 비율로 정리)
10/13UWO 크로스월드 웹 작업 회의

UWO 사업 측 요청 6건(크로스월드 11/25)의 가능 여부와 일정 협의. 참석: 이진우 실장, 김영환 팀장, 테디 팀장

결정

  • 11/25 게임 내 크로스월드는 사업 확정일. 웹 작업이 안 되더라도 그대로 개방
  • 웹 일정 모든 웹 작업은 12/8 스포2 오픈 이후 일괄 착수. 약 1개월, 1월 중순 완료 예상 (중간에 다른 작업이 끼지 않는 전제). 코브는 소스 확인 후 확정
  • 순서 랜딩(서버 선택) 제거 · 사이트 정리 → 팝업샵 · 컴퍼스 서버 선택 옵션 → 코브 수정 → 미스테리 코브
  • Lucky Wheel 운영 중단. 메뉴 제거, URL 직접 접근 차단, 소스는 보존
  • 지급 방식 서버 무관 은행 수령은 SRE 불가. Send to Bank 시 Maris / Ventus 선택 팝업으로 진행 (팝업샵 · 컴퍼스 동일)
  • 웹 로그인 이벤트 2024년 이벤트와 동일하게, 이전 소스 재사용

주요 논의

  • 미스테리 코브 기존 TC보다 약 20% 저렴. 열쇠 가격 정책 · 아이템 테이블 · 어드민을 별도로 만들어야 하고 공통 플랫폼이라 키만 바꾸면 다른 게임에 영향. 개발 1~2개월, 11/25 불가
  • Treasure Cove 크로스월드는 서버 통합이 아니어서 당분간 Maris / Ventus 코브 2개 유지 가능성. 통합 여부는 소스 확인 후
  • 디자인 미스테리 코브와 일반 코브는 최소 배경색으로 구분, 가능하면 디자인 개선. 미스테리 코브는 저가 느낌이되 너무 싸 보이지 않게. 디자인 요청은 착수 시
  • 플로팅 배너 Maris ↔ Ventus 이동용이라 불필요해질 수 있음. 제거 여부 미정
  • 배경 Ventus 런칭 때 적절한 시기에 크로스월드를 개방한다고 공지함
  • 개발팀 일정 스포2 빌링 · 세팅 · API 정리, 클로저스 Steam 오픈(11월 중순) 대응과 겹침
