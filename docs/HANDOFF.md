# 인계 문서 (2026-10-16 기준)

다른 Claude 계정에서 이 작업을 이어가기 위한 문서. 새 채팅에서 이 저장소를 연결하고 이 파일과 `CLAUDE.md`를 먼저 읽는다.

## 1. 상황

- 사용자: 테디 팀장 (Vertigo Games 그래픽디자인팀 팀장). 서비스개발실(그래픽디자인팀 + 플랫폼개발팀)의 웹기획을 사실상 맡고 있음. 결정권자는 아님. 서비스개발실장 자리는 공석.
- 웹기획자가 없어 역할·절차·일정이 정리되지 않은 상태라, 테디 팀장이 가이드와 일정 페이지를 만들어 관리 중.
- 페이지 두 개를 이 저장소 원본에서 생성해 Claude 아티팩트로 게시해 왔음. 이전 계정 소유라 새 계정에서는 같은 링크로 다시 게시할 수 없음 (아래 4번).
- 다음 단계: 컨플루언스로 옮기기 (Atlassian 커넥터는 새 계정에서 연결).

## 6. 작성 규칙

- 응답은 존댓말, 짧고 바로 쓸 수 있는 문장. 사용자는 반말로 짧게 씀. 원인부터 짚는 걸 선호
- 이름 표기 고정, 참석자는 직급 순. "승인" 대신 "확정". 작성자가 잡은 날짜는 "제안"
- 결정이 바뀌면 이전 기록을 지우지 않고 `(MM/DD 변경: …)`
- 설명조 문장, 양식 섹션 넣지 않음. 사람 평가·인사·채용·사적인 사유는 페이지에 넣지 않음
- 녹음 텍스트는 이름·용어가 자주 깨짐 (예: 민재 = 고민제 PM, 비즈메카). 확실하지 않으면 이름을 붙이지 않고 확인 필요
- 한 곳을 고치면 같은 내용이 있는 표·카드·간트·안건을 모두 맞춤
- 회의 녹음 원문은 저장소에 넣지 않음. 정리된 회의록만
