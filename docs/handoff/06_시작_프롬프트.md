# 06. 시작 프롬프트

새 채팅에서 이 폴더의 파일을 모두 첨부한 뒤, 아래 프롬프트를 붙여넣고 대괄호 부분을 채워서 보냅니다.

---

```
첨부한 파일은 스포2 한국 런칭 웹 업무 가이드를 만들면서 정리한 작업 방식이야.
00_README부터 05까지 먼저 읽고, reference/sf2-web-guide.html의 구조와 스타일을 참고해서
서비스개발실 웹 업무 전체를 관리하는 페이지를 만들어줘.

나는 서비스개발실에서 웹 디자인과 웹기획을 맡고 있고, 결정권자는 아니지만
웹 업무가 어떻게 굴러가는지 파악하고 가이드를 주는 입장이야.

[관리할 프로젝트]
- 프로젝트명 / 결정권자 / PM / 웹기획·디자인 / 웹 개발 / 오픈 목표일 / 현재 단계
- 예: 스페셜포스2 한국 런칭 / 김충곤 팀장 / 고민제 PM / 테디 팀장 / 오중수 (총괄 김영환 팀장) / 12/8 / 사전예약 디자인
- [프로젝트 2]
- [프로젝트 3]

[공통 인원]
- 이름, 직함, 소속, 역할 (예: 에릭 실장 – SRE 인프라실, 인프라·기술 자문)

[이번 버전에서 먼저 필요한 것]
- 예: 전체 현황 탭과 프로젝트별 간트, 인력별 작업 현황

진행 방식:
1. 먼저 02_페이지_구조를 기준으로 이 페이지의 탭 구성을 제안하고, 모르는 정보는 질문해줘.
2. 내가 확인하면 첫 버전을 만들어서 아티팩트로 게시해줘. 간트는 04 문서의 스크립트 방식으로.
3. 그다음부터는 내가 회의 녹음 텍스트나 결정 사항을 주면 03_운영_방식 규칙대로 갱신해줘.
4. 사람에 대한 평가는 페이지에 넣지 말고, 확실하지 않은 내용은 확인 필요로 표시해줘.
```

---

## 미리 준비할 것

- 진행 중인 웹 프로젝트 목록과 각 프로젝트의 결정권자, PM, 담당자
- 각 프로젝트의 오픈 목표일과 이미 정해진 마일스톤
- 최근 회의록이나 녹음 텍스트 (있으면 첫 버전부터 반영 가능)
- 인원 명단 (이름 표기, 직함, 소속)
- 지금 겪고 있는 문제 2~3개 (페이지가 무엇부터 해결해야 하는지 정하는 기준)

## 스포2 페이지 이어서 관리하기

스포2 페이지는 기존 링크 그대로 계속 갱신할 수 있습니다. 새 채팅에서 스포2 페이지를 고치려면 기존 아티팩트 링크를 함께 주고 "이 페이지를 읽고 이어서 수정해줘"라고 하면 됩니다. 새 통합 페이지에 스포2를 프로젝트 하나로 넣을지, 따로 둘지는 처음에 정하세요.
