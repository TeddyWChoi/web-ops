# 04. 디자인 · 기술 규칙

스포2 페이지(`reference/sf2-web-guide.html`)의 구현 방식입니다. 새 페이지도 같은 방식으로 만들면 스타일이 통일됩니다.

## 형식

- **Claude 아티팩트(HTML 한 파일)**로 게시. 같은 파일 경로로 다시 게시하면 링크가 유지됨
- Word나 엑셀보다 이 방식을 쓰는 이유: 링크 하나로 공유, 간트·탭 같은 화면 구성 가능, 갱신이 빠름
- 탭 전환은 주소 해시(`#guide`, `#schedule`, `#minutes`, `#agenda`)로 처리해서 탭별 링크 공유 가능

## 스타일

- 글꼴: IBM Plex Sans KR (본문), IBM Plex Mono (번호·날짜 라벨). 대체 글꼴로 Apple SD Gothic Neo, Malgun Gothic 지정
- 색은 모두 `:root` 토큰으로 정의하고 다크 모드 값을 따로 둠

```css
:root {
  --bg: #f6f7f9; --surface: #ffffff; --fg: #1b2230; --muted: #5d6677; --line: #dde1e8;
  --accent: #2b4fb8; --accent-soft: #e8edfa;   /* 진행 중, 예정 */
  --flag: #9a5b00;  --flag-soft: #fdf1dc;      /* 위험, 확인 필요 */
  --ok: #1f7a4d;    --ok-soft: #e3f3ea;        /* 완료 */
}
```

- 레이아웃: 데스크톱은 왼쪽 목차 + 본문, 모바일(860px 이하)은 1단. 표와 간트는 각자 가로 스크롤
- 카드 테두리·그림자는 필요한 곳에만. 모든 블록을 카드로 만들지 않음

## 간트 차트

간트는 손으로 HTML을 쓰지 않고 **데이터 → 스크립트 → HTML** 순서로 만듭니다. (`reference/gantt_generator.py`)

```python
START=date(2026,10,1); END=date(2026,12,12); PX=8   # 하루 = 8px
teams = [
  ('웹기획 · 디자인', '테디 팀장', [
    # (업무명, 시작, 끝, 상태, 추정여부, 일정 칸 문구)
    ('홈페이지 디자인 · 검수', date(2026,10,2), date(2026,10,8), 'done', False, '완료'),
    ('사전예약 디자인', date(2026,10,14), date(2026,10,20), 'plan', True, '기획 확정 후 착수'),
  ]),
]
miles = [(date(2026,10,2),'킥오프'), (date(2026,12,8),'웹사이트 오픈')]
```

- 상태값: `done`(완료) / `now`(진행 중) / `plan`(예정) / `warn`(위험) / `tbd`(날짜 없음, 막대 없이 문구만)
- 추정 일정(`True`)은 점선 테두리
- 날짜 없는 업무도 행은 만들고 "기한 미정"으로 표시 (빠진 일이 보이게)
- 스크립트는 HTML 안의 간트 블록만 교체하므로, 데이터만 고치고 다시 실행하면 됨
- 하루 8px이면 10~12월(약 10주)이 약 580px. 기간이 길어지면 PX를 줄이거나 주 단위로 바꿈

### 마일스톤 라벨 겹침

마일스톤이 가까우면(예: 11/10과 11/16) 라벨이 겹칩니다. `reference/milestone_stagger.py`처럼 라벨을 위·아래 두 줄로 나누고, 오른쪽 끝 라벨은 왼쪽으로 붙입니다. 간트를 다시 생성할 때마다 이 스크립트도 다시 실행합니다.

### 오늘 선 자동 이동

페이지를 열 때마다 보는 사람의 날짜로 오늘 선이 움직입니다. 막대 상태는 자동으로 바뀌지 않으므로, 오늘 선을 넘긴 "진행 중" 막대가 보이면 갱신이 밀린 것입니다.

```js
var START = new Date(2026, 9, 1), END = new Date(2026, 11, 12), PX = 8;
var now = new Date(), today = new Date(now.getFullYear(), now.getMonth(), now.getDate());
var days = Math.round((today - START) / 86400000);
var inRange = today >= START && today <= END;
document.querySelectorAll('.g-today, .g-todaytag').forEach(function (el) {
  el.hidden = !inRange; el.style.left = (days * PX + PX / 2) + 'px';
});
document.querySelector('.g-todaytag').textContent = '오늘 ' + (today.getMonth()+1) + '/' + today.getDate();
```

## 여러 프로젝트로 늘릴 때

- 데이터를 프로젝트별로 나눠 한 파일(JSON 또는 파이썬 딕셔너리)에 모으고, 같은 생성 함수로 프로젝트별 간트와 전체 요약 간트를 모두 만듦
- 인력별 작업 현황은 같은 데이터를 사람 기준으로 다시 묶어서 생성 (업무마다 담당자 필드를 두면 자동으로 가능)
- 겹침 경고: 같은 사람의 막대 기간이 겹치면 `warn` 표시

## 검증

게시 전에 한 번 확인합니다.

- 헤드리스 브라우저(Playwright)로 일정표 탭을 열어 간트 영역만 캡처해서 라벨 겹침, 막대 위치 확인
- 오늘 선은 날짜를 임의로 바꿔 한 번 테스트 (예: 11/3으로 넣고 선 위치 확인)
- 스크립트 문법 오류 확인: 페이지 안 `<script>`를 `new Function()`으로 한 번씩 파싱
- 페이지 전체 텍스트를 뽑아서 예전 담당자·예전 결정이 남아 있지 않은지 대조

## 하지 말 것

- 복사 버튼이 달린 양식 섹션 (지라 양식과 겹쳐서 혼선)
- 섹션 첫머리 안내 문장
- 탭 제목 앞에 같은 단어 라벨 반복 (예: "논의 논의 안건")
- `alert()`·`confirm()` 같은 브라우저 대화상자 (아티팩트에서 동작하지 않음)
