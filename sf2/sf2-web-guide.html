00이 문서에 대해

스포2 웹 업무는 고민제 PM이 중심이 되어 진행하고, 최종 결정은 김충곤 팀장이 합니다.

웹 관련 요청, 문의, 검수 의견은 고민제 PM을 통해 주고받습니다. 고민제 PM을 통해 해결되지 않는 건은 김충곤 팀장에게 올립니다. 일정, 범위, 오픈 여부는 김충곤 팀장의 결정으로 확정되며, 대표님 결정이 필요한 사항은 김충곤 팀장이 올립니다. 실무자 사이의 합의만으로는 일정이나 범위가 바뀌지 않습니다.

  • 적용 범위 스페셜포스2 공식 웹사이트, 재런칭 페이지, 이벤트·프로모션 페이지
  • 소통 도구 웹 작업·수정 요청은 지라, 디자인팀과 사업팀 간 소통은 팀즈. 일정 변경과 긴급 이슈는 SF2 공통 채널
  • 개정 정기 회의에서 수정 의견을 받아 반영

한국 공식 홈페이지와 사전예약 페이지 개발, 한국 플랫폼 연동과 SF2 연결을 맡습니다. 한국 API·로그인 테스트, 19세 인증 처리가 포함됩니다.

04상황별 대응

오픈 일정이 밀릴 것 같을 때

  1. 지연이 생긴 팀의 팀장이 지연 대상, 사유, 새 일정, 결정이 필요한 사항을 정리합니다.
  2. SF2 공통 채널에 올리고 고민제 PM과 김충곤 팀장을 태그합니다.
  3. 김충곤 팀장이 확정하면 일정이 바뀐 것으로 봅니다. 확정 전까지는 기존 일정이 유효합니다.
  4. 다른 게임 일정에 영향이 있으면 에릭 실장, 인프라에 영향이 있으면 션 팀장에게도 공유합니다.
  5. 고민제 PM이 변경 내용을 일정표와 다음 정기 회의 내용에 반영합니다.

실무자끼리만 합의한 일정 변경은 효력이 없습니다. 반드시 김충곤 팀장 확정을 거칩니다.

수정 요청이 생길 때

  1. 수정 요청은 사업팀 안에서 정리한 뒤 고민제 PM이 한 번에 전달합니다. 실무자에게 개별로 들어온 요청은 고민제 PM을 거치도록 안내합니다.
  2. 웹기획 단계라면 테디 팀장이 기획안을 고칩니다.
  3. 디자인 확정 전이라면 테디 팀장이 반영합니다.
  4. 디자인 확정 후나 개발 중이라면 김영환 팀장이 일정 영향을 판단합니다. 일정이 바뀌면 위의 지연 절차를 따릅니다.
  5. 검수 의견은 고민제 PM이 수정 목록 하나로 모아 한 번에 전달합니다.

확정 이후의 범위 추가는 김충곤 팀장 확정 없이 받지 않습니다.

오픈 직전이나 직후 긴급 이슈가 생길 때

  1. 발견한 사람이 SF2 공통 채널에 즉시 올리고 김영환 팀장과 오중수를 태그합니다.
  2. 김영환 팀장이 원인과 예상 조치 시간을 회신합니다.
  3. 오픈 연기나 페이지 내림이 필요하면 김충곤 팀장이 결정하고, 고민제 PM이 공지합니다.

누가 맡을지 애매할 때

  1. 업무별 담당 표를 먼저 확인합니다.
  2. 그래도 불분명하면 테디 팀장에게 문의합니다. 테디 팀장은 담당자를 안내하고, 필요하면 정기 회의 안건으로 올립니다.
  3. 사업팀 쪽 문의는 고민제 PM에게 하고, 해결되지 않으면 김충곤 팀장에게 올립니다.
